# Quantum Computing for Everyone!
#### By Chris Bernhardt
This is the first of a series of notes based on the Book "Quantum Computing for Everyone".

It provides an introduction to QC topics which are essential for understanding QML algorithms. Also, I believe it is essential to understand QC before diving into QML the same way it is essential to understand Classical computing before getting into ML.
